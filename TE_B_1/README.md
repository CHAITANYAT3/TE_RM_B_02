# CO2 Emission Prevention – Research Prototype

Research Methodology Lab, Experiment 7. V1.1 adds a CSV of example factors and loads the car factor from the CSV.

## Run
From inside this project folder: `python src/main.py`

## Data
`data/emission_factors.csv` holds **illustrative** kg CO2 per passenger-km factors.

## Disclaimer
Numbers are examples for reproducibility and demonstration, not verified reference measurements.
