# CO2 Emission Prevention – Research Prototype

Research Methodology Lab, Experiment 7. V1.0 initial working prototype.

## Aim
Estimate example car travel CO2 emissions from a distance entered by a user.

## Run
From inside this project folder: `python src/main.py`

## Disclaimer
The factor 0.192 kg CO2 per passenger-km is illustrative for this class demo, not a validated official emissions factor.
