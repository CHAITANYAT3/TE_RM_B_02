# CO2 Emission Prevention – Research Prototype

Research Methodology Lab, Experiment 7. V1.2 compares car, bus and train for the same distance.

## Run
From inside this project folder: `python src/main.py`

## Example
Distance: 10 km; example totals: car 1.920 kg, bus 0.820 kg, train 0.410 kg CO2 per passenger.

## Disclaimer
Numbers are illustrative, not validated reference measurements.
